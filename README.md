# Gershon-Hybrid-manikin-bronchosocopy-and-OLV-trainer
STLs to adapt an existing airway manikin into a hybrid anatomically correct airway trainer. Printing and assembly instuctions can be found here https://journals.lww.com/simulationinhealthcare/abstract/2024/02000/development_and_validation_of_a_hybrid.8.aspx
With thanks to all the staff at the Levin Center for Surgical Innovation and 3D Printing
This model is for educational purposed only and must not be used for clinical decision making or commercial reasons
